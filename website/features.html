./resesh / features

everything in the app, and what comes next.

a tabbed ssh and local-terminal client for windows, built for daily use.

winui 3 · .net 10 ssh.net transport webview2 + xterm.js gpl-2.0

everything in the beta, then everything planned, in order. rows marked planned aren't built yet.

01 sessions and identity

a folder tree of saved sessions with fast search, per-session settings overrides, and icon packs — linux distros, network os vendors, or your own drop-in icons — so a tab is recognisable at a glance.

  • local shell profiles on conpty: powershell, cmd, wsl, git bash
  • agent-aware tabs with attention badges (claude code, codex, gemini cli)
  • color tags carried onto the tab accent
[ IMAGE ] sessions.png — tree with icons and color tags
02 keyword highlighting

regex rule packs for the things you actually scan for — interfaces, ip and mac addresses, up/down states, routing protocols — toggled per session, extended with your own rules.

GigabitEthernet0/1 is up, line protocol is up GigabitEthernet0/2 is down, line protocol is down
[ IMAGE ] highlighting.png — rule editor beside live output
03 annotated scrollbar

an overview ruler mapping the whole scrollback: search matches, highlight hits, bookmarks and command marks with exit-status colors, plus per-line timestamps.

  • command discovery via osc 133, osc 3008 and enter-gated marks
  • terminal search on ctrl shift f
[ IMAGE ] ruler.png — marks on the overview ruler
04 command list

every command the session ran, listed in order with its exit status. jump straight to where it happened in the scrollback, or copy just that command's output — no selecting across a screenful of prompts.

show ip interface brief jump copy
systemctl restart bird  exit 1 jump copy
[ IMAGE ] commands.png — command list with jump and copy
05 recording and rewind

bounded in-memory rewind with xterm state keyframes, so you can scrub backwards through a live terminal without disconnecting. every session writes paired asciicast v2 and timestamped plain-text logs.

  • .cast playback with pause, speed and seek
  • plain logs you can grep six months later for the post-mortem
[ IMAGE ] rewind.png — scrubber over a live terminal
06 workspaces and layout restore

named tab-group layouts that remember order, pinned and active tabs. open one to replace what's on screen or add to it, adopting connections that are already live.

  • clean-exit startup restore
  • conflict-aware remapping when a backup is imported
[ IMAGE ] workspaces.png — workspace picker with tab groups
07 file transfer and browsing

local and sftp file panes in the app, following the terminal's current directory — cmd and powershell prompts, tmux, osc 7, a /proc probe, and prompt parsing as fallback.

  • open local folders straight in explorer
  • remote folders through sshfs-win when it's installed
[ IMAGE ] sftp.png — file pane following the terminal
08 keys, secrets and host keys

private keys are shared named resources with fingerprint pinning and path repair. passphrases and passwords live in windows credential manager, never in the json store.

  • explicit keyboard-interactive prompts
  • host-key mismatch override dialog, accepted keys stored locally
[ IMAGE ] keys.png — key registry with fingerprints
09 backup, export, import

*.reseshbackup archives with a versioned schema and merge-on-import. secrets are excluded by default; include them and the whole archive is encrypted with its passphrase.

  • securecrt session import
  • atomic writes with one .bak rotation
[ IMAGE ] import.png — securecrt import summary
10 gssapi / kerberos auth
planned

log in with the windows ad ticket — no password or key stored anywhere. a timeboxed spike settles the approach first, since ssh.net has no gssapi-with-mic support. clear failure messaging for missing tickets, clock skew and spn mismatch, falling back to a password prompt.

planned

a per-session tunnel list — local, remote and dynamic socks — started with the connection, with live status in the tab and an add-tunnel action on a running session. then agent auth over the windows openssh named pipe and pageant. then jump hosts: pick an existing session as the hop, chains resolved recursively with a cycle check.

console-cable and terminal-server access. telnet with minimal iac negotiation and naws wired to resize; quick connect takes telnet host:2003 for terminal-server line ports. serial with baud, parity and flow control, friendly com-port names, live device arrival, cable-yank survival, and send break for boot interrupts. highlighting, the ruler and recording work unchanged on both.

deliberately not doing

resesh doesn't want to do it all

no embedded scripting language personally I think automation belongs in ansible or netconf/gnmi style tooling, run from a trusted host where it's versioned and reviewed.
no broadcast input the classic multi-device-typo footgun on a heterogeneous fleet. anything worth sending to n devices at once is worth a playbook.
no automatic shell-integration injection osc 133 and osc 7 setup can be shown and copied if you want it. resesh never sends setup code to your shell on its own.

where your data lives

sessions and folders %APPDATA%\Resesh\sessions.json
workspaces and layout %APPDATA%\Resesh\workspaces.json
passwords and passphrases windows credential manager
accepted host keys %APPDATA%\Resesh\known_hosts.json

secrets are never written to the normal json store, and they're left out of backups unless you ask for them.
