features and planned work

manage SSH sessions and local terminals on windows.

winui 3 · .net 10 ssh.net transport webview2 + xterm.js gpl-2.0

current features are listed first. rows marked planned aren't built yet.

01 saved sessions

save sessions in folders, filter by name, and set terminal options for each host. choose an included icon or add your own.

  • local profiles for powershell, cmd, wsl and git bash
  • tab badges for claude code, codex and gemini cli
  • color tags carried onto the tab accent
02 keyword highlighting

highlight interfaces, IP and MAC addresses, link states and routing protocols. enable rules per session or write your own regular expressions.

GigabitEthernet0/1 is up, line protocol is up GigabitEthernet0/2 is down, line protocol is down
03 annotated scrollbar

the scrollbar shows search matches, highlighted text, bookmarks and command positions. command marks can show exit status; line timestamps show when output arrived.

  • command detection from shell signals and terminal input
  • terminal search on ctrl shift f
04 command list

view detected commands in order, with exit status where available. select a command to find it in the terminal or copy its output.

show ip interface brief jump copy
systemctl restart bird  exit 1 jump copy
05 recording and rewind

rewind earlier output in the native terminal while the session continues. enable recording to save an asciicast file and a timestamped text log.

  • .cast playback with pause, speed and seek
  • text logs for searches and change records
06 workspaces and layout restore

save pane sizes, tab order, pinned tabs and the active tab. open a workspace on its own or add it to the current layout.

  • restore the last layout on startup
  • keep workspace session references when importing backups
07 file transfer and browsing

browse local files and transfer remote files over SFTP. the file pane can follow the terminal folder when resesh can detect it.

  • open local folders straight in explorer
  • remote folders through sshfs-win when it's installed
08 keys, secrets and host keys

name and reuse private-key references across sessions. view fingerprints and update the path if a key file moves. passwords and passphrases are stored in windows credential manager.

  • explicit keyboard-interactive prompts
  • review changed host keys before accepting them
09 backup, export, import

export a .reseshbackup archive and merge it into another installation. passwords and passphrases are excluded by default. including them requires an encrypted backup.

  • review sessions before importing them
  • keep a previous copy of saved data
10 themes

choose a light or dark theme for the app and terminals. use a different terminal theme for each session.

  • included themes such as dracula, nord, tokyo night and catppuccin mocha
  • preview theme changes in settings; save to keep them or cancel to restore the previous theme

scope

resesh is a terminal client. these functions stay outside the app.

no embedded scripting language run automation with tools such as ansible from your shell.
no broadcast input keyboard input goes to one terminal at a time. use an automation tool to run commands across several hosts.
no automatic shell-integration injection resesh reads shell integration signals when available. it does not send setup commands to remote shells.

where your data lives

sessions and folders %APPDATA%\Resesh\sessions.json
workspaces and layout %APPDATA%\Resesh\workspaces.json
passwords and passphrases windows credential manager
accepted host keys %APPDATA%\Resesh\known_hosts.json

secrets are never written to the normal json store, and they're left out of backups unless you ask for them.
