01 / command history new

find the command you ran last tuesday

turn on command history and resesh keeps each finished command with its output, host, folder, time and exit result. search all of it from one place, then put the command back at a prompt or reopen the session it ran in.

  • · every word must match the command, host, folder or output
  • · narrow with host:syd-pe in:/etc exit:fail, or pick a day on the calendar
  • · off by default, local only, and left out of backups
ctrl shift h open command history

03 / sessions and workspaces

organise hosts, then keep the layout

group sessions in folders and give each one a name, icon and colour. open them in tabs or split panes, then save the tabs, pane sizes and positions as a named workspace for the next maintenance window.

  • · passwords and passphrases stay in windows credential manager
  • · terminal theme, highlighting and history settings per session
  • · remote shells survive a dropped connection inside a private tmux server
ctrl shift p open a workspace from the command palette
04 / coding agents

run claude code over ssh

coding agents on a remote host behave the way they do in a local terminal. tabs show when an agent is working or waiting for you.

  • · copy from a remote program straight to the windows clipboard
  • · shift enter adds a new line instead of submitting
  • · full colour, emoji at the right width and clickable links
  • · progress on the tab and taskbar, and an opt-in notification when a command finishes
$ ssh build-01 && claude osc 52 copy     → windows clipboard (write-only) shift+enter     → esc cr, a new line in the prompt xtversion       → "resesh", so synchronized output turns on colorterm       → truecolor, sent with the ssh session osc 9;4         → progress on the tab and taskbar ● agent waiting → amber badge on the tab

05 / telnet

console servers, lab gear, and the odd bbs

telnet sessions share the session list, tabs, splits, highlighting, history and recordings with ssh. the window size follows the tab, and send break works through a console server.

  • · text encoding per session: automatic, utf-8 or cp437 for ansi art
  • · report 80 × 25 to bbs servers while the tab keeps its real size
  • · type telnet host 2003 in quick connect to reach a console line
06 / rewind

scroll back in time, not just up

rewind shows the terminal as it was minutes ago while the session keeps running, then returns to live. turn on recording to keep an asciicast file for playback and a text log you can search.

questions

anything missing, open an issue on github.

is it free? yes. the source code is available on github.
where is my session data stored? saved sessions and recordings are stored locally. resesh does not require a cloud account.
does command history keep passwords i type? output can contain secrets, so history is off until you turn it on, and each session can opt out. it stays on this pc, is left out of backups, and deleted entries are overwritten on disk. entries older than 90 days are removed by default.
where are credentials kept? in the windows credential store, encrypted per user. resesh never writes a password to its own config files.
which protocols are supported? ssh, telnet and local shells. serial support is planned.
does it work with claude code, codex or gemini cli? yes, locally and over ssh. tabs show when an agent is working or needs you, remote copies reach the windows clipboard, and shift enter inserts a new line.
what are the keyboard shortcuts? press ctrl shift / in the app for the full list, or open the command palette with ctrl shift p. shortcuts never take plain ctrl and letter keys from the shell.
mac or linux? resesh currently runs on windows only.
