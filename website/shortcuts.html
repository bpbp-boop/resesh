keyboard shortcuts

every shortcut in resesh, grouped by where it works. the same list is in the app on ctrl shift /, where you can search it.

ctrl shift p runs any action by name plain ctrl and a letter stays with the shell no ctrl alt chords

application, tab and split view shortcuts work anywhere in the window, including while a terminal has focus. terminal shortcuts need a focused terminal, and session tree shortcuts need the focus in the tree. keys are named as on a us keyboard. the list in the app shows what your layout prints on them.

left to the shell

keys resesh does not take, so the programs you run still get them.

plain ctrl and a letter ctrl w, ctrl r, the tmux prefix ctrl b and the rest always reach the shell. this is why most shortcuts here add shift.
ctrl alt no shortcut uses it. on many european layouts ctrl alt is altgr, which types characters.
alt and an arrow in an unsplit window resesh takes these, and alt shift and an arrow, only to move focus or a tab between split groups. with one group they go to the shell.
ctrl shift c with nothing selected copy needs a selection. without one the key goes to the shell, and so does ctrl insert.
